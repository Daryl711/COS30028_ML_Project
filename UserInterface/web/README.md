Identifies the crop and disease in a leaf photo, including crop-disease combinations that never appear in the training images (DPD-Small: 55 crops, 175 diseases, 323 seen and 10 unseen combinations). The model runs in the browser with ONNX Runtime Web, and shows training images that match the prediction.
